Markdown Cheat Sheet With Copyable Examples

Markdown is plain text with a few symbols that turn into formatting. It is what most AI chat tools write, what README files use, and what note apps store. This sheet lists the syntax you will actually need, in GitHub-flavored Markdown, with a copy button on each example.

Headings

# Title
## Section
### Subsection

Emphasis

**bold**, *italic*, ~~strikethrough~~, `inline code`

Lists

- item
- item
  - nested item

1. first
2. second

Task list

- [x] done
- [ ] to do

Links and images

[link text](https://example.com)
![alt text](image.png)

Code block

```python
print("hello")
```

Table

| Name | Qty |
|:-----|----:|
| Apples | 3 |
| Pears | 12 |

Quote and rule

> quoted text

---

Footnote

A claim.[^1]

[^1]: The source.

Five mistakes that break rendering

  • No blank line before a list or table. Many renderers treat it as part of the previous paragraph.
  • Mixed list markers. Switching between - and * inside one list can split it in two.
  • Table rows with a different number of cells. The table silently breaks. A Markdown table generator avoids counting pipes by hand.
  • Unclosed code fences. Everything after an unclosed ``` becomes code.
  • Leftover artefacts from AI chats. Stray escape characters and odd spacing; a Markdown formatter cleans these up.

Checking how it will look

Different apps render Markdown slightly differently. Before you send a file to someone, paste it into a live Markdown preview and look at it on a phone as well as a laptop. If the recipient does not have a Markdown app, they will see the raw symbols; the guide on how to open an MD file explains the options.
